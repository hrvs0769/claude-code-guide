07 · 工作流自动化

使用 Agent 模式和后台任务实现自动化。

Agent 模式

Claude Code 支持长时间运行的 Agent 任务：

# 启动 Agent 模式
claude agent

# 指定任务目标
claude agent --task "重构整个项目的错误处理"

后台任务

🔄 后台执行

使用 & 在后台运行长时间任务，不阻塞对话。

📊 任务监控

使用 jobs 命令查看后台任务状态。

🛑 任务控制

fg 将后台任务切换到前台，kill 终止任务。

自动化脚本

创建自动化脚本实现常见工作流：

# 自动化代码审查
claude agent --task "审查 PR #123 并给出建议"
# 批量文件处理
claude agent --task "重命名所有 component 为 PascalCase"
💡 v2.1.77 注意事项

后台 bash 任务输出超过 5GB 会自动终止，防止磁盘空间耗尽。
