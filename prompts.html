03 · 高效提示词

编写高质量提示词，获得更准确的回答。

核心原则

1. 明确任务目标

清楚说明你希望 Claude 做什么，达到什么目的。

✗ 模糊：帮我优化代码
✓ 明确：帮我优化这段 React 组件的性能，减少不必要的 re-render
2. 提供上下文

说明代码的用途、所在项目、相关依赖等信息。

✓ 完整上下文：这是一个 Next.js 13 的 API route，使用 Prisma 连接 PostgreSQL...
3. 指定输出格式

告诉 Claude 你期望的输出形式（代码、解释、步骤列表等）。

高级技巧

分步指令

复杂任务分成多个步骤，让 Claude 逐步完成。

角色扮演

指定 Claude 扮演特定角色（如资深前端工程师、技术面试官）。

示例引导

提供输入输出示例，帮助 Claude 理解你的期望格式。
