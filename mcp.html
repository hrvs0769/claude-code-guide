05 · MCP 扩展

通过 MCP 服务器扩展 Claude Code 能力。

什么是 MCP

MCP (Model Context Protocol) 是 Claude Code 的扩展协议，允许连接外部服务和工具。

配置 MCP 服务器

# ~/.claude/mcp.json
[
{
"name": "filesystem",
"command": "npx",
"args": ["@modelcontextprotocol/server-filesystem", "./my-project"]
}
]

常用 MCP 服务器

📁 文件系统服务器

访问和操作本地文件系统

🐙 GitHub 服务器

操作 GitHub 仓库、PR、issues

🗄️ 数据库服务器

连接数据库执行查询操作

🔍 搜索服务器

全项目代码搜索和导航

常用命令

  • mcp list - 查看已配置的 MCP 服务器
  • mcp add - 添加新的 MCP 服务器
  • mcp remove - 移除 MCP 服务器
