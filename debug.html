06 · 调试与排错

常见问题诊断与解决方案。

诊断命令

# 检查 Claude Code 状态
claude doctor

# 查看详细日志
claude logs --verbose

# 检查配置
claude config list

常见问题

❓ API 密钥无效

运行 claude config set api-key 重新设置 API 密钥。

❓ 连接超时

检查网络连接，或使用 claude config set proxy 配置代理。

❓ 会话中断

使用 claude sessions list 查看历史会话，用 /resume 恢复。

❓ 权限被拒绝

检查 ~/.claude/settings.json 中的沙箱配置是否正确。

日志分析

日志文件位于 ~/.claude/logs/ 目录。使用以下命令查看：

# 查看最近 100 行日志
tail -n 100 ~/.claude/logs/claude.log
