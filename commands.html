02 · 核心命令

掌握所有斜杠命令，高效使用 Claude Code。

常用命令

/help

显示所有可用命令和快捷键

/help
/resume 或 /r

恢复最近中断的会话

/resume
/branch 或 /b

从当前会话创建新分支（之前叫 /fork）

/branch my-feature
/review-pr

审查 GitHub pull request

/review-pr 123
/copy

复制最近一次回复到剪贴板（v2.1.77 新增支持索引）

/copy # 复制最近一次回复
/copy 2 # 复制倒数第 2 条回复

会话命令

/sessions

列出所有会话

/sessions
/switch

切换到另一个会话

/switch session-id
💡 技巧： 直接在消息前加斜杠 / 即可触发命令自动补全。
