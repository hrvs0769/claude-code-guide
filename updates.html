08 · 版本更新

了解最新版本的新功能与迁移指南。

v2.1.77 最新特性

最新版本

2025 年更新

✦ 输出 token 上限提高到 128k，支持更长上下文的对话
✦ 新增 allowRead 沙箱设置，可在 denyRead 区域内重新允许读取
✦ /copy 命令支持索引 /copy N 复制倒数第 N 条回复
✦ 后台 bash 任务输出超过 5GB 自动终止，防止磁盘爆满

更新 Claude Code

# npm 更新
npm update -g @anthropic-ai/claude-code

# 或 pnpm 更新
pnpm update -g @anthropic-ai/claude-code

# 查看版本
claude --version
