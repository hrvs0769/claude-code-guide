01 · 基础入门

从零开始，掌握 Claude Code 的安装、配置和基本使用方法。

安装 Claude Code

Claude Code 可以通过多种方式安装，推荐使用 npm 全局安装：

# 使用 npm 安装
npm install -g @anthropic-ai/claude-code

# 或使用 pnpm
pnpm add -g @anthropic-ai/claude-code

💡 提示

需要 Node.js 18+ 版本才能运行 Claude Code。安装前请确认已安装 Node.js。

配置 API 密钥

首次使用前，需要配置 Anthropic API 密钥：

# 设置 API 密钥
claude config set api-key your-api-key-here

获取 API 密钥：

  • 访问 Anthropic Console
  • 创建新 API 密钥并妥善保存
  • 将密钥粘贴到配置命令中

开始对话

# 启动交互式对话
claude

启动后直接输入你的问题或需求，Claude Code 会分析并执行。

会话管理

  • 查看会话列表： claude sessions list
  • 恢复会话： claude session resume [会话ID]
  • 新建会话： claude session new
