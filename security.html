04 · 权限与安全

了解沙箱设置、权限管理，确保安全使用。

沙箱模式

Claude Code 默认在沙箱环境中运行，可通过配置文件调整权限：

# ~/.claude/settings.json
{
"sandbox": {
"allow": ["read", "write"],
"deny": ["/path/to/sensitive"]
}
}

⚠️ 安全提醒

谨慎配置允许写入的目录，避免意外修改重要文件。

allowRead 新增功能 (v2.1.77)

在 denyRead 区域内重新允许读取特定目录：

# 允许读取 node_modules 即使在 denyRead 区域
{
"sandbox": {
"denyRead": ["*"],
"allowRead": ["./src", "./node_modules"]
}
}

敏感数据保护

  • ✓ 避免在对话中直接输入 API 密钥
  • ✓ 使用环境变量存储敏感信息
  • ✓ 定期检查配置文件权限
  • ✓ 谨慎使用 /copy 命令复制敏感内容
